# Skills

Skills are specific abilities that each hang off one attribute.

## Skill values

A skill's base value is **half its attribute** (rounded down). Training adds points on top.

> **Example:** With Dexterity 60, Stealth starts at 30 untrained. With 25 points of training, it's 55.

## Skill lists are per-world

STARS has no fixed skill list. Each world defines the skills that matter in it. The lists below are examples to start from.

| Attribute | Example skills |
| --- | --- |
| **Strength** | Athletics, Brawl, Melee |
| **Dexterity** | Stealth, Ranged, Sleight of Hand, Drive/Pilot |
| **Intellect** | Notice, Investigate, Medicine, Lore (specific) |
| **Charisma** | Persuade, Deceive, Intimidate, Insight |
| **Powers** | Resolve, plus setting-specific power skills |

### Genre examples

- **Sci-fi:** Pilot (DEX), Engineering (INT), Hacking (INT)
- **Fantasy:** Arcana (INT), Survival (INT), Riding (DEX)
- **Modern crime:** Firearms (DEX), Streetwise (CHA), Forensics (INT)
