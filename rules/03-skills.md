# Skills

Skills are specific abilities that each hang off one attribute.

## Skill values

A skill's base value is **half its attribute** (rounded down). Training adds points on top.

> **Example:** With Dexterity 60, Stealth starts at 30 untrained. With 25 points of training, it's 55.

## Skill lists are per-world

STARS has no fixed skill list. Each world defines the skills that matter in it. The lists below are examples to start from.

| Attribute | Example skills |
| --- | --- |
| **Strength** | Athletics, Brawl, Melee |
| **Dexterity** | Stealth, Ranged, Sleight of Hand, Drive/Pilot |
| **Intellect** | Notice, Investigate, Medicine, Lore (specific) |
| **Charisma** | Persuade, Deceive, Intimidate, Insight, Resolve |
| **Powers** | Setting-specific disciplines (see below) |

### Genre examples

- **Sci-fi:** Pilot (DEX), Engineering (INT), Hacking (INT)
- **Fantasy:** Arcana (INT), Survival (INT), Riding (DEX)
- **Modern crime:** Firearms (DEX), Streetwise (CHA), Forensics (INT)

## Power skills

Every skill under Powers is a **discipline**: one kind of extraordinary ability. Disciplines follow the normal skill rules. They start at half Powers and improve with training, and using one is an ordinary test.

> **Example:** Mavessa has Powers 50, so Pyrokinesis starts at 25. With 30 points of training it's 55. Hurling fire at a guard is a Pyrokinesis test against 55, with difficulty and situational modifiers as usual.

Like other skills, each world defines its own disciplines. For example:

- **Fantasy:** Evocation, Healing, Illusion, Necromancy
- **Psionic sci-fi:** Telepathy, Telekinesis, Precognition
- **Superheroes:** Flight, Super-Strength, Energy Blast, Invulnerability
- **Faith-based:** Blessing, Warding, Exorcism

How powerful each discipline is, and what it costs to use, is still being decided. See [`docs/open-questions.md`](../docs/open-questions.md).
