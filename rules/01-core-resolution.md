# Core Resolution

## The roll

When the outcome of an action is uncertain, the character makes a **test**:

1. Find the relevant **target number**, usually a skill (or an attribute, if no skill fits).
2. Apply any **difficulty modifier**.
3. Roll **d100** (two d10s, one for tens and one for ones; 00 = 100).
4. If the roll is **equal to or under** the modified target, the test succeeds.

## Difficulty modifiers

| Difficulty | Modifier |
| --- | --- |
| Easy | +20 |
| Routine | +10 |
| Standard | ±0 |
| Hard | −20 |
| Extreme | −40 |

Situational modifiers (good tools, injuries, cover, and so on) stack with difficulty.

### Limits

After all modifiers, the target number is capped at **95** and floored at **5**. There is always some chance of failure and some chance of success.

## Degrees of success

| Result | Condition |
| --- | --- |
| **Critical** | Roll is equal to or under one-tenth of the target (rounded down, minimum 1) |
| **Success** | Roll is equal to or under the target |
| **Failure** | Roll is over the target |
| **Fumble** | Roll is 96–100 |

A critical gives an extra benefit (more damage, more information, faster, quieter). A fumble adds a complication on top of failure.

> **Example:** Rafael has Stealth 55 and is sneaking past a bored guard (Routine, +10), so his target is 65. A roll of 01–06 is a critical, 07–65 a success, 66–95 a failure, and 96–100 a fumble.

## Opposed tests

When two characters act against each other, both roll against their own targets.

- If only one succeeds, they win.
- If both succeed, the **higher successful roll** wins. A critical beats a normal success.
- If both fail, nobody wins and the situation stays unresolved, or shifts in some small way.
